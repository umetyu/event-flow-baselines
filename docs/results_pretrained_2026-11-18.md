## RNN-EV-FlowNetの不一致について

原因は未特定。分かっていること:

- 評価の手順は共通で、同じ構造の部品を使う他のモデル(RNN-FireNet、EV-FlowNet、Leaky-EV-FlowNet)は一致している。評価側の誤りとは考えにくい。
- 論文の値(0.56 / 0.62 / 1.20 / 0.93、1.91 / 2.23 / 4.01 / 3.07)は、NeurIPS版のPDFを2回読み直して同じだった。
- 元コードの設定ファイルには「RNNRecEVFlowNetは学習率5e-5」という注記がある。一方、配布物の記録では学習率2e-4になっている。この記録ファイルは、他の多くのモデルと同じく後から書き換えられた形跡がある(更新日時が他の記録より新しく、1バイト長い)。
- 以上から「配布された重みが、表の数値を出した学習とは別のもの」という可能性が高いと見ているが、確かめていない。学習率5e-5で再学習すれば検証できる(`configs/exp/s2_rnn-evflownet-cnt_w1000_seed0.yml` がその設定)。
